Evidence Transparency

Every clinical tool and reference in Anestheo carries a traceable evidence trail.

A permanent evidence identity

Each calculator and reference is tied to a permanent evidence identifier that never changes, kept separate from the tool's routing name. That separation means the audit trail stays stable even if a tool is renamed or moved.

A documented review lifecycle

Clinical content moves through an explicit review state before it is published, and only reviewed, published content is served to clinicians. The lifecycle is tracked so it is always clear what has been reviewed and what has not.

Seeing the evidence in context

Where a tool surfaces a recommendation, the underlying evidence can be opened alongside it, so you can check the basis for a value rather than taking it on trust. Browse the full library from Clinical references.
