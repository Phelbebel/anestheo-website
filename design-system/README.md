# The Anestheo Design System — v1.0

This is not a style guide. It is the operating system from which every Anestheo
page, product, workspace, and asset is generated.

There is one rule above all the others: **everything derives from `FOUNDATION.md`.**
The Foundation is what we believe; everything in this folder is how that belief
becomes visible. If a design decision cannot be traced back to a line in the
Foundation, it does not belong to Anestheo.

A new designer should be able to read these documents and produce work that is
unmistakably ours — without asking anyone a question.

### Read in this order

1. **FOUNDATION.md** — why the company exists. Read it first, and often.
2. **DESIGN_PRINCIPLES.md** — the eight beliefs every screen obeys.
3. **POINT.md** — the soul of the system. The steady light.
4. **TYPOGRAPHY.md** · **COLOR.md** · **LAYOUT.md** · **MOTION.md** — the materials.
5. **COPY.md** — the voice.
6. **COMPONENTS.md** — the parts.
7. **PRODUCT_PRESENTATION.md** — how the work is shown.

### Governance — the locks on the system

- **DESIGN_DECISIONS.md** — what we rejected, and why. Read before re-proposing it.
- **NORTH_STAR.md** — the ten-question review every screen passes before shipping.
- **CHANGELOG.md** — Version 1.0, frozen. Evolution is encouraged; redefinition
  requires founder approval.

### The shape of every document

Every document explains **why before how.** The reasoning is not preamble — it
is the load-bearing part. The specifications can change as tools change; the
reasons are why they were ever chosen, and they outlive the tools.

### The test

Hold any future work against three questions:

- Does it express a line of the Foundation?
- Could you remove something and make it stronger?
- Would it still look correct in 2045?

If yes to all three, it is Anestheo. If not, it is not finished.
